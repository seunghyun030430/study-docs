# CLAUDE.md

## 이 레포의 목적

"AWS Systems Manager(SSM)"를 실무 관점에서 정리하는 문서 중심 저장소다. 코드 프로젝트가 아니라 지식 정리/문서화가 핵심이며,
정확성과 출처가 코드 실행보다 우선한다.

- 중점 기능: **Session Manager**, **Parameter Store**, **Run Command / Automation**
- 공통 기반(SSM Agent, managed node, IAM, 네트워크)은 개요·아키텍처 문서에서 다룬다.
- 예제는 별도 `examples/` 없이 **문서 내 AWS CLI 코드블록**(`bash`)으로 둔다.

> 정리할 구체적 범위는 사용자가 지정한다. 임의로 문서를 양산하지 말 것.

## 작성 원칙

- **사실 기반**: 사실 주장에는 1차 출처(AWS 공식 문서·요금 페이지·CLI 레퍼런스) URL을 함께 단다.
- **추측 금지**: 확신이 없으면 "확인 필요" 또는 "모름"으로 명시.
- **결론 우선**: 결론을 먼저, 근거를 뒤에.
- **비교는 표로**: 선택지·개념이 여러 개면 비교표로.
- **균형**: 권장 사항뿐 아니라 안티패턴·한계·주의사항도 함께.
- **용어**: 기술 용어·고유명사는 원문 그대로(예: managed node, SecureString, runbook), 필요하면 한글 설명을 곁들인다.
- **변동 정보**: 요금·한도(quota)·기능 제공 여부는 자주 바뀌므로 조사 기준일과 함께 적고, 공식 페이지 링크를 남긴다.

## 문서 컨벤션

- 모든 문서는 Markdown(`.md`). 본문 서술은 한국어, 코드·식별자·고유명사는 원문.
- 파일명은 `0N-<주제>.md` 번호 순서.
- 제목 계층은 `#`(문서당 1개) → `##` → `###` 순으로만.
- 문서 맨 위에 `> 한 줄 핵심 요약`, 맨 아래에 `## 출처`와 `*조사 기준일: YYYY-MM-DD*`.
- 인용은 `> "원문" — 출처` 형식.
- CLI 예시는 ` ```bash ` 코드펜스, 리소스 ID·계정 ID는 `i-0123456789abcdef0`, `111122223333` 같은 예시 값을 쓴다.
- 날짜는 절대 표기(예: 2026-10-12). 상대 표현 지양.

## 커밋 규칙

- 문서 1개 = 커밋 1개. 메시지는 `docs: <한글 설명>`.
- 관련 파일만 스테이징(`git add <파일>`), `git add -A` 지양.

## 작업 시 주의

- 요청 범위 안에서만 작업. 문서 과잉 생성·과잉 리팩토링 금지.
- 기존 문서를 고칠 때 출처와 사실관계를 먼저 확인하고 수정한다.
